- Added class-level `<summary>` XML doc comments to all 12 classes/interfaces/enums under `src/Retention/` (including the private nested `RetentionStrategy.SplitGenerator`), each explaining the GFS-retention concept the type represents rather than restating its members. The user subsequently hand-edited several of these doc comments for concision (`IRetentionInterval.cs`, `DailyInterval.cs`, `WeeklyInterval.cs`, `MonthlyInterval.cs`, `YearlyInterval.cs`, `RetentionStrategyOptions.cs`) and added member-level doc comments to `IRetentionInterval`'s methods.
- **Bug 1 (silent data loss):** `RetentionStrategy.Evaluate` (`RetentionStrategy.cs:34-35`) used `sortedCandidates.Index().FirstOrDefault(...).Index` to find the boundary between "always retain" (newer than `StartPoint`) and "subject to policy evaluation" candidates. When *no* candidate is `<= StartPoint` (e.g. `StartPoint` predates the whole data set, or clock skew), `FirstOrDefault` returns `default` = index `0`, which the code misread as "nothing is newer than StartPoint" instead of "everything is." Reproduced with a scratch console app: 10 candidates all newer than `StartPoint` → only 1 retained, 9 wrongly pruned. Fixed by switching to `List.FindIndex` with an explicit fallback to `sortedCandidates.Count` when no match is found. Added regression test `Evaluate_AllCandidatesNewerThanStartPoint_RetainsAll` in `RetentionStrategyTests.cs`.
- **Bug 2 (hang / DoS):** `RetentionPolicy.Parse`'s regex (`^(\d+)(D|W|M|Y):(\d+)(D|W|M|Y):(N|O)$`) accepted `0` as a valid interval count (e.g. a typo like `"1M:0D:N"`). A zero-count `KeepInterval.Subtract` is a no-op, so `RetentionStrategy.SplitGenerator`'s `while (split > PeriodStart)` loop (`RetentionStrategy.cs:112-120`) never terminates — confirmed via a reproduction that hung indefinitely (killed after a 10s timeout). Fixed by adding `ArgumentOutOfRangeException.ThrowIfLessThan(count, 1)` to the constructors of `DailyInterval`, `WeeklyInterval`, `MonthlyInterval`, `YearlyInterval`, so bad input now fails fast at `Parse`/construction time instead of hanging inside `Evaluate`. Added zero/negative-count constructor tests to all four interval test files, plus `Parse_WithZeroCount_ThrowsArgumentOutOfRangeException` in `RetentionPolicyParseTests.cs` covering both the period and keep positions.
